# Sophistle

> A daily game of logical fallacy detection. Watch a real exchange, find the fallacies, match each one to the right speaker and phrase.

## Concept

Each day, Sophistle presents a short video of an exchange between two or more speakers. The exchange contains **one or several logical fallacies**. The player's task is to identify them.

The goal is to train critical thinking through a daily, low-pressure, shareable habit.

## How to play

1. Watch the daily video.
2. Read the transcript, in which each speaker is clearly distinguished.
3. Select a phrase in the transcript.
4. Assign a fallacy to it from the list of possible fallacies.
5. Submit. Each answer is checked against two criteria:
   - **the fallacy** is the correct one;
   - **the phrase and speaker** it is attached to are the correct ones.
6. Review the correction, which includes a short explanation of why each phrase is fallacious.

A single exchange may contain several fallacies. The player must find all of them.

## Content

- **One new exchange per day**, shared by all players.
- Videos are drawn from **recent news around the world**.
- Content can be **matched to the country being played**, so that players see exchanges relevant to their region (for example, a French player may be shown French political or media debates).
- Every exchange is annotated in advance with its fallacies, their exact location in the transcript, and an explanation.

## Game modes

| Mode | Format | Source | Status |
|---|---|---|---|
| **Daily** | Video + transcript | Recent news | Core |
| **Archives** | Written exchanges | Historical texts from the far past (for example, philosophical dialogues, public debates, speeches) | Planned |
| **Fiction** | Written or transcribed exchanges | Fictional literature (novels, plays, scripts) | Planned |

Non-video modes use the same mechanics: a text with identified speakers, a list of fallacies, and matching to phrases.

## Interface

The page layout contains, at minimum:

- **The video player**, for video-based modes.
- **The transcript**, displayed next to or below the video, with **each speaker visually distinguished** (name, colour, or both).
- **The fallacy list**, from which the player picks.
- **The source panel**, showing where the exchange comes from and who contributed it (see [attribution rules](#sourcing-and-attribution-rules)).

Non-video modes display the transcript alone.

## Community contributions

Players can **submit video links** to be considered for upcoming rounds (days).

- A submission consists of a link, and optionally the proposed fallacies and timestamps.
- Submissions are reviewed before being scheduled.
- Accepted submissions are credited to their contributor.

## Sourcing and attribution rules

For every exchange:

- The **original source** (channel, outlet, publication, date) must be displayed.
- The **contributor**, where there is one, must be displayed.
- Videos are **linked or embedded from their original host**, not re-hosted.
- Transcripts must identify speakers accurately and reflect what was actually said.

## Fallacy catalogue

The player picks from a defined list. A candidate initial list:

| Fallacy | Short description |
|---|---|
| Ad hominem | Attacking the person instead of the argument |
| Straw man | Misrepresenting a position to refute it more easily |
| Appeal to authority | Treating a claim as true because an authority asserts it |
| Appeal to emotion | Replacing evidence with emotional pressure |
| Appeal to popularity | Treating a claim as true because many believe it |
| False dilemma | Presenting only two options when more exist |
| Slippery slope | Asserting that one step inevitably leads to an extreme outcome |
| Circular reasoning | Using the conclusion as a premise |
| Hasty generalisation | Drawing a broad conclusion from too few cases |
| Post hoc | Assuming that what follows an event was caused by it |
| Whataboutism | Deflecting criticism by pointing to another issue |
| Red herring | Introducing an irrelevant topic to divert attention |
| Tu quoque | Dismissing a criticism because the critic is also guilty of it |
| Burden of proof shift | Demanding that others disprove a claim rather than supporting it |

This list is expected to evolve. Each fallacy needs a precise definition and an example to keep annotation consistent.
